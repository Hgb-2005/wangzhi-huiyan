# 网址慧眼 · 后端接口对接说明

> 当前状态：**规则演示模式**（mock 数据）
> 目标状态：接入 Flask 后端后切换为**真实检测模式**，关闭所有演示标注

---

## 一、切换原理

前端逻辑层与数据层已分离。切换时只需替换 `engine.js` 中三个函数的**数据来源**，判定逻辑与渲染层完全不动：

| 函数 | 当前实现 | 接入后改为 |
|---|---|---|
| `detect()` | 读 `mockCaseData` | 调用 `POST /api/detect` |
| `recommend()` | 读 `mockSiteDB` | 调用 `POST /api/recommend` |
| 短链解析 | mock 跳转链 | 调用 `POST /api/resolve` |

## 二、需要后端提供的接口

### 1. 短链解析 `POST /api/resolve`

**请求**
```json
{ "url": "https://t.cn/x9k2Lm", "maxRedirects": 5 }
```

**响应**（对应规范步骤2）
```json
{
  "original": "https://t.cn/x9k2Lm",
  "final": "https://account-verify.demo-login.top/signin",
  "chain": [
    { "hop": 1, "url": "https://t.cn/x9k2Lm", "status": 301 },
    { "hop": 2, "url": "https://account-verify.demo-login.top/signin", "status": 200 }
  ],
  "exceeded": false
}
```
> `exceeded: true` 时前端显示「循环跳转，可疑」并终止解析。

---

  },
  "icp": {
    "hasIcp": true,
    "subjectName": "某某科技有限公司",

### 3. 站点推荐 `POST /api/recommend`

**请求**
```json
{ "keyword": "流程图", "constraints": { "free": true, "noAd": true, "online": true }, "limit": 3 }
```

**响应**
```json
{
  "total": 3,
  "sites": [
    {
      "id": 1,
      "name": "某某流程图工具",
      "url": "https://example.com/flow",
      "tags": ["流程图", "绘图"],
      "summary": "一句话简介",
      "scene": "流程梳理",
      "free": true,
      "hasAd": false,
      "historyCheckTime": "2026-10-20",
      "historyLevel": "safe",
      "liveLevel": "safe"
    }
  ]
}
```

> ⚠️ `liveLevel` 必须是**本次实时复测结果**。后端需对每个候选站点调用一次通道A的检测接口。
> `liveLevel === "danger"` 的站点必须过滤，不返回给前端。

## 三、错误码约定

前端按以下 `code` 走对应固定话术：

| HTTP | code | 前端提示 |
|---|---|---|
| 504 | `TIMEOUT` | 后端检测服务请求超时，本次仅完成本地URL特征简易检查… |
| 429 | `QUOTA_EXHAUSTED` | 安全检测接口额度已用尽，仅可展示域名基础信息… |
| 502 | `CRAWL_BLOCKED` | 无法获取网页简介，该站点页面信息抓取失败。 |
| 400 | `INVALID_URL` | 识别到不是有效网址，请检查链接… |
| 400 | `TOO_MANY_URLS` | 单次最多支持同时检测5条链接… |

## 四、降级触发点

后端在以下情况返回 `degradeLevel` 字段，前端据此渲染降级提示：

| 场景 | `degradeLevel` | 前端行为 |
|---|---|---|
| 第三方安全API挂 | `L1` | 关闭黑名单标记，标注识别能力大幅下降 |
| 页面抓取失败 | `L2` | 简介位置显示【页面抓取失败，暂无站点介绍】 |
| 站点库检索异常 | `L3` | 暂停推荐，提示维护中 |
| 短链解析故障 | `L4` | 仅检测原始链接，提示无法查看真实跳转目标 |

## 五、切换 checklist

接入完成后按顺序执行：

- [ ] `engine.js` 中 `mockCaseData` / `mockSiteDB` 删除
- [ ] `detect()` / `recommend()` 改为 `fetch` 调用真实接口
- [ ] index.html 中 `.demo-banner` 横幅移除
- [ ] `demoFlag()` 改为空函数（移除所有"演示数据"角标）
- [ ] 答辩演示模式 `demoMode()` 移除
- [ ] 保留 `routeInput` / `localFeatures` / `checkProhibited` — 这三个是纯本地规则，**永久有效**，不依赖后端
- [ ] 真实接口抽测：高危站不得显示为安全；未知站不得编造备案信息

## 六、测试建议

后端完成后重点验证这几组：

| 输入 | 预期 level |
|---|---|
| 形近钓鱼站（数字替换字母） | `danger` |
| 新注册域名 + 短链 + 境外服务器 | `suspicious` |
| 备案齐全的老牌站点 | `safe` |
| 无法访问的站点 | `unknown` |
| 循环跳转短链 | `suspicious` + 循环告警 |
